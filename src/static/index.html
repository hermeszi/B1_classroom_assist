Quick Start — How to use CARE

New here? This guide explains the basic workflow

1

Optional - Today's lesson - type the topic (e.g. "Prime Numbers, Colour Theory...") and a brief description of what you covered with the whole class. This is optional but helps the AI write better summaries.

2

Select student(s) - tick one student, or tick several at once if you taught a group together.

3

Add quick notes - a few words is enough. Any observations? What did the student do? Any challenges or achievements? You can also dictate using the mic button.

4

Generate & Save - the AI writes the full summary. Review it, edit if needed, then Save to keep it on the student's record.

5

Optional - get student feedback - after saving, CARE shows a link you can share with the student. They rate the lesson (1–5 stars) and their feedback is used to improve future summaries.

💡 First time? Go to the ⚙ Settings tab first to enter your API key. You can use OpenRouter, OpenAI, Groq, or a local Ollama model.

Student Feedback Links

Collect ratings and comments directly from your students

1.

Click Get Link next to any saved lesson to create a unique feedback URL for that student.

2.

Share the link — show it on your screen, message it to the student, or put it in a class chat.

3.

The student rates the lesson (1–5 stars) and leaves optional comments. Their response is saved automatically.

4.

Feedback appears in the lesson history and is fed into future AI reports — so the AI learns how the student feels.

No internet required. The feedback page is served by the same app. On the same WiFi: share the http://…:8001/feedback.html?token=… link directly. Once you deploy to a public server, links work from anywhere. You can also connect this to Google Forms or a similar tool in the future.
